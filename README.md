# 📈 InvestIQ
---
## AI-Powered Stock Portfolio Intelligence Platform

InvestIQ is a full-stack stock portfolio management and analytics platform designed to help users **track investments, analyze portfolio performance, evaluate risk, explore market data, receive portfolio recommendations, and interact with an AI-powered investment assistant** through a modern dashboard.

---

## ✨ Overview

InvestIQ combines portfolio management, market intelligence, quantitative risk analysis, and AI-assisted insights into a single platform.

The application provides an interactive dashboard where users can:

* Add and manage stock investments
* Monitor portfolio value and daily gains
* View portfolio holdings
* Analyze portfolio allocation and performance
* Explore stock market information
* Evaluate portfolio risk
* Receive investment recommendations
* Ask questions through an AI portfolio assistant

---

---

## 🛡️ Portfolio Risk Analysis

InvestIQ evaluates portfolio risk using quantitative financial metrics.

### Sharpe Ratio

Measures the excess return generated by a portfolio per unit of risk.

### Volatility

Measures the variability or dispersion of portfolio returns.

### Value at Risk (VaR)

Estimates the potential loss of a portfolio over a specified time period at a specified confidence level.

### Maximum Drawdown

Measures the largest peak-to-trough decline in portfolio value during a specified period.

---

## 💡 Investment Recommendations

InvestIQ provides portfolio recommendations based on the available portfolio and market information.

The recommendation functionality is separated into:

```text
API Router
    ↓
Recommendation Service
    ↓
Recommendation Logic
```

This separation keeps API handling independent from application logic.

---

## 🤖 AI Portfolio Assistant

InvestIQ includes an AI-powered assistant that can answer questions about the user's portfolio.

The assistant uses information such as:

* Portfolio summary
* Current holdings
* Risk metrics
* Portfolio recommendations

The user's question is sent to the backend, where the AI service generates a contextual response.

### AI Request Flow

```text
AssistantPanel.tsx

Frontend API Service

POST /assistant/
        ↓
FastAPI Assistant Router
        ↓
AI Service
        ↓
Gemini API

AI Response
        ↓
AssistantPanel
```

# 🧩 Backend Architecture

The backend is organized into separate layers.

## API Layer

Located in:

```text
backend/app/api/
```

The API layer defines FastAPI routes and handles HTTP requests.

Examples:

```text
/dashboard
/portfolio
/market
/recommendation
/risk
/stocks
/assistant
```

The routers delegate application logic to the service layer.

---

## Service Layer

Located in:

```text
backend/app/services/
```

The service layer contains application and business logic.

Examples:

```text
dashboard_service.py
portfolio_service.py
market_service.py
recommendation_service.py
risk_service.py
stock_service.py
ai_service.py
```

The separation follows:

```text
API Router
    ↓
Service
    ↓
Database / External API / AI
```

---

## Database Layer

Located in:

```text
backend/app/database/
```

Responsible for database configuration and SQLAlchemy setup.

---

## Models

Located in:

```text
backend/app/models/
```

Database entities are represented using SQLAlchemy models.

---

## Schemas

Located in:

```text
backend/app/schemas/
```

Pydantic schemas define and validate API request and response data.

# 🔌 API Endpoints

## Dashboard

```http
GET /dashboard/
```

Returns dashboard-level portfolio information.

---

## Portfolio

```http
POST /portfolio/
```

Adds an investment.

```http
GET /portfolio/
```

Returns portfolio holdings.

```http
GET /portfolio/summary
```

Returns portfolio summary information.

```http
DELETE /portfolio/{portfolio_id}
```

Deletes a portfolio holding.

---

## Market

```http
GET /market/{ticker}
```

Returns stock information.

```http
GET /market/{ticker}/history
```

Returns historical stock price information.

```http
GET /market/portfolio/history
```

Returns historical portfolio information.

---

## Recommendation

```http
GET /recommendation/
```

Generates portfolio recommendations.

---

## AI Assistant

```http
POST /assistant/
```

Accepts a portfolio-related question and returns an AI-generated response.

Example request:

```json
{
  "question": "How is my portfolio performing?"
}
```

# ⚙️ Installation

## Prerequisites

Install the following:

* Python 3.x
* Node.js
* npm
* Git

---

# 1. Clone the Repository

```bash
git clone https://github.com/<your-username>/InvestIQ.git
cd InvestIQ
```

---

# 2. Backend Setup

Navigate to the backend:

```bash
cd backend
```

Create a Python virtual environment:

### Windows

```bash
python -m venv .venv
```

Activate it:

```bash
.venv\Scripts\activate
```

Install dependencies:

```bash
pip install -r requirements.txt
```

---

# 3. Configure Environment Variables

Create a `.env` file inside the backend directory:

```env
GEMINI_API_KEY=your_gemini_api_key_here
```

Never commit your `.env` file or expose your API keys publicly.

Make sure `.gitignore` contains:

```gitignore
.env
.venv/
venv/
node_modules/
__pycache__/
*.py[cod]
```

---

# 4. Start the Backend

From the `backend` directory:

```bash
uvicorn app.main:app --reload
```

The FastAPI backend will run at:

```text
http://127.0.0.1:8000
```

Interactive API documentation:

```text
http://127.0.0.1:8000/docs
```

---

# 5. Frontend Setup

Open a new terminal.

Navigate to:

```bash
cd frontend
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the URL provided by Vite in your browser.
